# Requisitos Não-Funcionais

O sistema deve atender aos seguintes requisitos não funcionais:

## RNF01 - Plataforma de Desenvolvimento

O sistema deverá ser desenvolvido como um aplicativo mobile.

## RNF02 - Usabilidade da Interface

O sistema deverá possuir interface simples e de fácil utilização.

## RNF03 - Compatibilidade

O sistema deverá ser compatível com dispositivos Android.

## RNF04 - Acesso via Navegador Web

O sistema deverá permitir que os clientes consultem o status de seus serviços por meio de navegadores web.

## RNF05 - Desempenho

O sistema deverá apresentar tempo de resposta rápido nas operações.

## RNF06 - Segurança

O sistema deverá garantir a segurança das informações dos usuários e clientes.

## RNF07 - Armazenamento de Dados

O sistema deverá armazenar os dados em banco de dados.

## RNF08 - Conectividade

O sistema deverá funcionar com conexão à internet.

## RNF09 - Usabilidade

O sistema deverá possuir boa usabilidade, sendo intuitivo para os usuários.

## RNF10 - Manutenibilidade

O sistema deverá permitir fácil manutenção e atualização.

## RNF11 - Estabilidade

O sistema deverá apresentar estabilidade durante sua execução.

## RNF12 - Integridade dos Dados

O sistema deverá garantir a integridade dos dados cadastrados.

## RNF13 - Boas Práticas de Desenvolvimento

O sistema deverá seguir boas práticas de desenvolvimento de software.
