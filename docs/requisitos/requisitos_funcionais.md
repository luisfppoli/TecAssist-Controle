# Requisitos Funcionais

O sistema deve atender aos seguintes requisitos funcionais:

## RF01 - Gerenciamento de Usuários

O sistema deve permitir o cadastro de usuários (administrador e funcionário).

## RF02 - Autenticação de Usuários

O sistema deve permitir que usuários realizem login no sistema conforme suas permissões de acesso.

## RF03 - Gerenciamento de Clientes

O sistema deve permitir o cadastro e gerenciamento de clientes.

## RF04 - Agendamento de Atendimentos

O sistema deve permitir o agendamento de atendimentos relacionados a serviços da assistência técnica.

## RF05 - Consulta de Agenda

O sistema deve permitir a visualização dos agendamentos em formato de lista ou calendário.

## RF06 - Controle de Estoque

O sistema deve permitir o controle de estoque de peças e equipamentos.

## RF07 - Movimentação de Estoque

O sistema deve registrar entradas e saídas de peças no estoque.

## RF08 - Registro de Serviços

O sistema deve permitir o cadastro de serviços realizados associados a clientes e aos funcionários responsáveis, podendo ser vinculados a um agendamento.

## RF09 - Histórico de Atendimentos

O sistema deve armazenar o histórico de serviços, incluindo registros de entrada de equipamentos, execução de serviços e entrega ao cliente.

## RF10 - Registro de Informações dos Serviços

O sistema deve armazenar as informações dos serviços realizados, incluindo equipamento, problema relatado, diagnóstico, solução e peças utilizadas.

## RF11 - Atualização de Status de Serviços

O sistema deve permitir a atualização do status dos serviços (ex: em andamento, concluído).

## RF12 - Consulta de Status dos Serviços

O sistema deve permitir que os clientes consultem o status atual de seus serviços.

## RF13 - Notificações

O sistema deve enviar notificações aos clientes sobre o andamento dos serviços.

## RF14 - Comunicação com Clientes

O sistema deve permitir que os funcionários preparem mensagens com informações sobre o andamento dos serviços para comunicação com os clientes.

## RF15 - Consulta de Clientes e Serviços

O sistema deve permitir a consulta de dados de clientes e serviços.

## RF16 - Edição e Exclusão de Registros

O sistema deve permitir a edição e exclusão de registros (clientes, serviços e estoque).

## RF17 - Busca de Informações

O sistema deve permitir a busca de informações por nome do cliente ou serviço.

## RF18 - Registro de Observações

O sistema deve permitir o registro de observações em cada atendimento.

## RF19 - Controle de Múltiplos Atendimentos

O sistema deve permitir o controle de múltiplos atendimentos simultaneamente.
